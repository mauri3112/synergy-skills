# Working on this collection

This repository is the maintained source for skills we create and a catalog of external skills we adopt.

- Keep skill packages under `skills/<name>/`. Read the affected `SKILL.md` and relevant references before changing its behavior.
- Preserve each skill's intended scope and the user's decisions. Do not apply the specification interview workflow merely because you are editing its instructions.
- Keep the root catalog and skill metadata consistent. Credit upstream influences, and record the source revision, license, and local changes for adopted or adapted third-party skills.
- Keep skills self-contained where practical. Add references, scripts, or dependencies only when they serve a concrete need.
- Validate changed frontmatter, local references, and any changed scripts. Distinguish structural validation from observed behavior in a real session.
- Update installed copies only when the user authorizes that update. Adding a catalog entry does not authorize installing a skill on every machine.
- Include only intentionally shared skill content and documentation. Do not import personal configuration, credentials, conversations, or project data from a local skills installation.
